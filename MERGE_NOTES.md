# Asal frontend RAMA-SVM-HOG

Frontend diambil dari branch silva pada commit
`3190f377ef034b6fa68db3a8360b45b5ed9c1e20`.

Tampilan, navigasi, kamera, upload, kamus, riwayat, progres, badges,
dan aset visual dipertahankan. Label pilihan model disesuaikan menjadi
SVM + HOG. Backend CNN, MediaPipe, dan model lama dilepas dari snapshot ini.

`SignClassifier` sementara menolak permintaan prediksi dengan pesan jelas.
Belum ada training, backend SVM-HOG, atau integrasi model baru.
Branch rama dan silva tetap tersimpan dengan model serta kode asalnya.

Lihat README.md untuk status dan REQUIREMENTS.md untuk setup frontend.
